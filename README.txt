VOCABULARY VAULT — install guide
=================================

Quickest: just open index.html (or GRE_Vocab_Trainer.html) in any browser. It works fully offline — no internet needed.

To install it like an app on your phone (works offline, has its own icon):
1. Upload ALL files in this folder to any free static host that uses https,
   e.g. GitHub Pages, Netlify Drop (app.netlify.com/drop) or Cloudflare Pages.
2. Open the site on your phone.
   - Android / Chrome: menu (⋮) > "Install app" or "Add to Home screen".
   - iPhone / Safari: Share button > "Add to Home Screen".
3. Open it once while online; after that it also works offline.

Your progress is stored inside the browser on that device. Use Progress > "Export backup file"
now and then to keep a copy, and "Import backup file" to move it to another device.
